# Anti-Bot / Anti-Detect Browser Automation for AI Agents — 2026 Comparison

Research performed Saturday, July 25, 2026. All citations are primary sources (project repos / official docs) accessed on this date unless noted. "Last commit" dates reflect what GitHub displayed at access time.

## (a) undetected-chromedriver

Verdict: **Stale, declining efficacy, no fingerprint spoofing.** Last commit on the master branch is "last year" (a Python 3.13 compatibility refactor); the README itself warns it "DOES NOT hide your IP address" and the project no longer makes any strong claims about modern bot-mitigation systems. The author has restricted the issue tracker due to abuse, and pinned discussion has moved to GitHub Discussions. It only patches chromedriver's `navigator.webdriver` and a handful of runtime flags — there is **no fingerprint/randomization system, no header-generation library, no WebRTC spoofing, no persistent fingerprint rotation**. Community reports in 2024–2025 (e.g. the patchright author's write-ups, and various Reddit/issue threads) consistently show uc failing Cloudflare Turnstile, Datadome, and Akamai BMCD on datacenter IPs. Persistent profiles work via `user_data_dir` like stock Selenium, but they don't gain you anything stealth-wise. Use it only for trivial logins where the only detector is `navigator.webdriver`. License: **GPL-3.0**. Python only.
Source: https://github.com/ultrafunkamsterdam/undetected-chromedriver (accessed 2026-07-25)

## (b) Patchright (Playwright stealth fork — Python + Node)

Verdict: **Currently the strongest open-source option for Chromium-based automation.** Last commit "last week" (commits 26332af / 0b64cf, README updated for NodeMaven sponsor); actively maintained by @Vinyzu. v1.58 released ~4 months ago, with continuous driver-version followups and a "Fix Release Workflow Driver Version" commit last month. License: **Apache-2.0**. Python (`patchright` on PyPI) and Node (`patchright-js`). Drop-in replacement for Playwright: `from patchright.sync_api import sync_playwright`. Its patches are concrete and named in the README: avoids `Runtime.enable` leak (executes JS in isolated contexts), disables `Console.enable`, removes `--enable-automation`, adds `--disable-blink-features=AutomationControlled`, removes `--disable-component-update`/`--disable-extensions`/`--disable-default-apps`/`--disable-popup-blocking` (all command-flag tells), and supports interaction inside closed shadow roots. The README explicitly claims passing: **Cloudflare ✅, Akamai ✅, Datadome ✅, Kasada ✅, Shape/F5 ✅, Bet365 ✅, Fingerprint.com ✅, CreepJS ✅, Sannysoft ✅, Incolumitas ✅, IPHey ✅, Browserscan ✅, Pixelscan ✅, Brotector ✅ (with CDP-Patches)**. Persistent profiles: yes — `launch_persistent_context(user_data_dir="…", channel="chrome", headless=False, no_viewport=True)` is the documented best practice and is what they recommend for "completely undetected" runs (use real Google Chrome, not Chromium). Caveat: **it does NOT rotate or spoof fingerprints** — the README's "Best Practice" section explicitly says to NOT inject custom UA/headers and to use a real Chrome profile, because the stealth model is "look like a real local Chrome," not "look like a different device." Detection rate vs DataDome/Akamai is community-reported as strong as long as you also supply a residential IP — Patchright handles the browser side, but it will not save you on a datacenter IP.
Source: https://github.com/Kaliiiiiiiiii-Vinyzu/patchright-python (accessed 2026-07-25); README: https://github.com/Kaliiiiiiiiii-Vinyzu/patchright-python/blob/main/README.md

## (c) Camoufox (anti-detect Firefox)

Verdict: **The most fingerprint-attention-rich open-source option; best when you need device rotation + multi-accounting, but immature.** Last commit "last week" (598 commits, 10.5k stars, 886 forks, 76 open issues). License: **GPL-3.0** (the main repo's /LICENSE; the pythonlib is Apache-2.0 companion-licensed). Python primary (`pip install -U "camoufox[geoip]"`), with a polished Qt GUI version manager (`camoufox gui`). README banner explicitly markets it as "an open source anti-detect browser built for webscraping & AI agents." The crucial differentiator: **all fingerprint spoofing happens at the C++ implementation level inside the Firefox binary**, not via JS injection — so JS inspection cannot detect that values are spoofed. Spoofed properties include navigator/screen/viewport/WebGL/audio context/device-voices/WebRTC IP (protocol-level)/geolocation/timezone/locale/battery, plus font fingerprinting defeat, automatic system-font bundling, and an opt-in `fingerprint_preset=True` mode that ships **312 real-world Firefox fingerprints** scraped from in-the-wild traffic (v149–v152: 67 macOS / 180 Windows / 65 Linux). Drop-in Playwright API (`from camoufox.sync_api import Camoufox`). Human-like mouse movement; uBlock Origin bundled; debloated (~200MB RAM, no CSS animations). Multiple version managed per-clone. Persistent profiles: yes, via Playwright `user_data_dir`. **The big caveat is in the repo's own banner: "⚠️ This project is under development. It may not be suitable for stable production use. ⚠️"**. The browser itself is now developed primarily at github.com/CloverLabsAI/camoufox and github.com/VulpineOS/VulpineOS; the daijro repo is the master checkpoint repo. The Python lib v0.5.4 was bumped last week. README does not publish a formal pass/fail matrix like Patchright's, but the stealth-overview doc enumerates dozens of patches (no `navigator.webdriver` leak, no headless pointer-type leak, frame execution context isolation, fission isolation, re-enabled PDF.js, etc.). It's the most ambitious open-source stealth story, but you accept breakage risk.
Source: https://github.com/daijro/camoufox (accessed 2026-07-25); README: https://github.com/daijro/camoufox/blob/main/README.md; Python docs: https://camoufox.com/python/installation/ (accessed 2026-07-25); active browser dev: https://github.com/CloverLabsAI/camoufox

## (d) Raw Playwright / CDP with stealth patches (playwright-stealth, etc.)

Verdict: **DIY route — less reliable than a maintained fork, and most "stealth" plugins are abandoned.** `playwright-stealth` (the old go-to) has been largely unmaintained for years — it injects JS shims that Cloudflare/Datadome now fingerprint via the mere *presence* of injection (isolated world artifacts, prototype tampering). The same is true of `puppeteer-extra-plugin-stealth`. The current best DIY route is: Patchright-style manual CDP patches on top of Playwright + BrowserForge-generated headers/fingerprints (`pip install browserforge[all]` — Apache-2.0, 1.2k stars, last commit 5 months ago,作者是Camoufox作者daijro). BrowserForge is a Bayesian generator that mimics real-world header/fingerprint frequency and is the de-facto fingerprint injection layer that Camoufox itself uses under the hood. License for raw Playwright is Apache-2.0. Detection rate: medium on Cloudflare, low on Datadome/Akamai unless you also patch `Runtime.enable` (which is exactly what Patchright does for you). Persistent profiles: Playwright supports `launch_persistent_context` natively. The DIY route is only worth it if you need a specific Chromium version Patchright hasn't shipped for, otherwise Patchright already *is* "raw Playwright + the correct stealth patches."
Source: https://github.com/daijro/browserforge (accessed 2026-07-25); https://playwright.dev/docs/api/class-browsertype#browser-type-launch-persistent-context

## (e) Commercial anti-bot browsers (Bright Data Browser API / Scrapfly / Sheeko / Kameleo)

Verdict: **Highest detection-bypass rates, lowest operational complexity, but paid and risk-prone for money-relevant actions.** Bright Data's paid Web Unlocker / Browser API (formerly "Scraping Browser") is the dominant commercial option: it's a hosted Chromium fleet exposed over CDP/WebSocket so you connect Puppeteer/Playwright/Selenium directly, with built-in CAPTCHA solving, residential IP rotation, and ASN/geo targeting. Pricing starts at **$5/GB** of browser traffic (per the pricing menu on brightdata.com/products/scraping-browser, accessed 2026-07-25). Bright Data retired their standalone "Agent Browser" marketing page (the /products/agent-browser URL returns 404 as of access date) and folded browser-stealth-for-agents into the "Data for AI → Agentic Web Execution → Agent Browser / Bright Data MCP (free)" umbrella. Scrapfly (a Camoufox sponsor listed in the README) is a competing Web Scraping API with similar managed-browser + fingerprint + proxy claims. Closed-source commercial anti-detect desktop products (Kameleo, Sheeko, Multilogin, GoLogin, Incognition, Dolphin{anty}) exist with monthly subscriptions (~$59–$300/mo), are not Python-controllable directly (they expose a local Playwright/Selenium driver endpoint), and ToS generally forbid the kind of money-relevant automation the user is doing (sign-ups, gig postings, surveys) — most explicitly prohibit "creating accounts" in their AUP. Persistent profiles: yes, that's their main feature. Detection rate vs Cloudflare/Akamai/Datadome: typically the highest in the market, because they have full-time teams matching fingerprint profiles to fresh residential IPs.
Sources: https://brightdata.com/products/scraping-browser (accessed 2026-07-25; pricing menu visible); https://brightdata.com/products/agent-browser (404, shows product has been folded into "Data for AI"); Scrapfly sponsor mention in https://github.com/daijro/camoufox/blob/main/README.md

## (f) Newer 2026 solutions worth tracking

- **CloverLabs Camoufox** (github.com/CloverLabsAI/camoufox) — the active-development fork of daijro/camoufox; adds per-context fingerprints + full **hardware spoofing** (GPU/RAM/CPU). This is where the real Camoufox browser engineering is happening now; the daijro repo publishes checkpointed releases. Installed via `pip install cloverlabs-camoufox`. GPL-3.0. Source: https://github.com/CloverLabsAI/camoufox (linked from daijro README, accessed 2026-07-25).
- **VulpineOS** (github.com/VulpineOS/VulpineOS) — a sibling fork in the same ecosystem, browser stack optimized for the same use cases. Linked from daijro README. Early stage.
- **BrowserForge** (covered in d) — the de-facto fingerprint generator both Camoufox and Patchright users should pair with their driver of choice. Source: https://github.com/daijro/browserforge.
- **Hermes/Stealth-agent stacks** — there's a 2026 trend of "agent browser" launchers (Bright Data's Agent Browser, Browserbase, Browserless v2, Steel.dev) that expose a hosted Patchright/Camoufox-equivalent over a thin Python SDK with built-in CAPTCHA solving. Steel.dev is open-source-friendly (Apache-2.0) and a genuinely new option in 2026 — worth a look as a fallback if you want a managed fleet without Bright Data's per-GB pricing.

No open-source replacement for Patchright + Camoufox has appeared that demonstrably beats them in 2026; the alternative ecosystem is mostly **commercial managed-browser APIs** and **fingerprint-data libraries (BrowserForge)** layered on the same two open-source drivers.

---

## FINAL RECOMMENDATION

**Primary: Patchright (Python) — Apache-2.0, actively maintained (last commit last week), explicitly passes Cloudflare/Akamai/Datadome/Kasada/Shape/F5, drop-in Playwright API, persistent profiles supported, and ships the *correct* CDP/runtime patches (Runtime.enable, Console.enable, command-flag leaks) you would otherwise have to write yourself.** Pair it with `channel="chrome"`, a real `user_data_dir`, `no_viewport=True`, headless=False, a residential proxy, and BrowserForge-generated headers when you *do* need fingerprint rotation across accounts.

**Fallback: Camoufox (Python, with the cloverlabs-camoufox pre-release binary) — when Chromium-based Patchright fails on a specific site, or when you need per-context fingerprint rotation + hardware spoofing + WebRTC-IP spoofing + a fundamentally different engine (Firefox) to dodge a detector that has Chromium fingerprints down cold.** Accept the GPL-3.0 license cost and "under active development" breakage risk; the README self-classifies as not-yet-production-stable.
